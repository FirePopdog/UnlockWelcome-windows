# Contributing

Thanks for your interest in contributing to UnlockWelcome.

## Development setup

1. Install the .NET 8 SDK with the Windows Desktop workload.
2. Clone this repository.
3. Run dotnet restore.
4. Open UnlockWelcome.csproj in Visual Studio or Visual Studio Code.
5. Run dotnet build -c Release.

## Pull requests

- Keep changes focused and explain the user-facing impact.
- Test on Windows 10 or Windows 11.
- Do not add telemetry, analytics, or network calls without an explicit discussion.
- Update the README when behavior or setup steps change.

## Bug reports

Include your Windows version, .NET runtime version, reproduction steps, and relevant error messages. Do not include personal information or private system paths.
